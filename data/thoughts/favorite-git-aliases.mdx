I recently cleaned up my `.gitconfig` and realized I use these aliases constantly:

```bash
[alias]
  st = status -sb
  co = checkout
  br = branch
  unstage = reset HEAD --
  last = log -1 HEAD
  visual = log --graph --oneline --all --decorate
```

## The One I Use Most

`git visual` has become indispensable. It shows me the branch structure at a glance:

```bash
* 2f1a3b4 (HEAD -> feature) Add new feature
* a1b2c3d Merge main into feature
|\
| * 9x8y7z6 (main) Fix bug
* | 5e6f7g8 Work on feature
|/
* 1a2b3c4 Initial commit
```

## Quick Tip

Add `alias.st=status -sb` to your config for a compact status view. The `-sb` flags give you a short, branch-aware status that's much easier to scan than the default output.
